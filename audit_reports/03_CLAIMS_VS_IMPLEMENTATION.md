## 2. Execution Path Tracing: UI to Detection Engine

### Trace A: Chat OCR Screenshot Verification Flow
1. **UI Layer:** User selects a screenshot in `ChatScreen` and taps analyze (`chat_screen.dart:124`).
2. **Controller Layer:** `_handleImageSelection()` converts the image to base64 bytes (`chat_screen.dart:135`).
3. **Egress Trigger:** Directly issues `http.post` to `https://api.ocr.space/parse/image` using hardcoded header `apikey: K87899142388957` (`chat_screen.dart:145`).
4. **Data Leakage:** Image containing user PAN card, banking OTP, or personal WhatsApp conversation is transmitted across the public internet to third-party servers.
5. **Detection Result:** Parsed text returned is passed to `LocalRuleEngine` or `AiExpertService` fallback.
6. **Verdict:** Complete breach of declared offline privacy posture.

### Trace B: App Scanner Sideload Heuristic Flow
1. **UI Layer:** User taps "Run Deep Scan" on `AppScannerScreen` (`app_scanner_screen.dart:210`).
2. **Data Source:** `InstalledApps.getInstalledApps(true, true, true)` queries Android `PackageManager` (`app_scanner_screen.dart:380`).
3. **Detection Engine:** Iterates each application through `_calculateRiskScore()` (`app_scanner_screen.dart:880`).
4. **Flawed Decision Branch:** `_isVerifiedEcosystem(app.packageName)` is called (`app_scanner_screen.dart:905`). If package starts with `com.google.`, `com.sbi.`, `com.whatsapp.`, etc.:
   - `isSideloaded` is forcefully set to `false`.
   - `riskScore` is artificially clamped to `<= 38`.
   - Threat level is overridden to "Safe" or "Low".
5. **Adversarial Exploitation:** A malicious APK package named `com.sbi.banking.trojan` requesting `RECEIVE_SMS` and `SYSTEM_ALERT_WINDOW` is classified as low risk.
