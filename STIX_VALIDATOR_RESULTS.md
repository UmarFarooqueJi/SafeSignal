## 3. ROOT CAUSE ANALYSIS OF VALIDATOR DEFECTS

1. **Relationship Type Character Restrictions:**
   - **OASIS Requirement:** STIX 2.1 Section 3.2 specifies that `relationship_type` must match the regex `^[a-z0-9-]+$`. Underscores (`_`) are strictly forbidden in standard STIX 2.1 relationship names.
   - **Current Implementation:** Emitted `hosted_on`, `resolves_to`, `drops_payload`.
   - **Fix Required:** Replace underscores with hyphens: `hosted-on`, `resolves-to`, `drops-payload` or utilize standard STIX relationships (`based-on`, `delivers`).
2. **Bundle Spec Version:**
   - In STIX 2.0, bundles had `spec_version: "2.0"`. In STIX 2.1, bundles omit `spec_version` at the root (it is declared inside each object).
3. **Custom Extension Properties:**
   - STIX 2.1 Section 11 recommends declaring an `extension-definition` object for custom metadata properties.
